# MatchVerse AI

## Run on Windows
Extract this folder and double-click `start-demo.bat`. The experience opens at localhost port 8080. Keep the command window open while presenting.

## Recommended flow
Start Match Analysis → MatchVerse → Decision Intelligence → Reality Compare → Match Story → Integrity.

## Key interactions
- Select Goal, Penalty, Goal Validation or Card Review.
- Use MatchVerse Copilot prompts.
- Select an audience and a language in Match Story.
- In Integrity, simulate an evidence change and restore the baseline.

Probability changes are modelled estimates for decision exploration. Human review remains authoritative.
